# Portfolio light-theme prototypes

Generated with the built-in image_gen tool for visual selection before implementation. No application code was changed.

## Options

1. [Warm editorial](01-warm-editorial.png): ivory, olive, serif headings, spacious project rows.
2. [Swiss clarity](02-swiss-clarity.png): white, black, blue links, a numbered project index.
3. [Quiet profile](03-quiet-profile.png): a left profile sidebar and a restrained reading column.
4. [Project gallery](04-project-gallery.png): warm white, terracotta accents, large conceptual app previews.
5. [Classic navy](05-classic-navy.png): centered serif typography, navy details, open project columns.

These images explore layout and theme. Small generated text, technology tags, and the contact email in option 3 are illustrative and must be replaced with verified app/data/portfolio.js content during implementation. Product screenshots in option 4 are conceptual previews, not captures of the real applications.

References: [Regular](https://www.framer.com/marketplace/templates/regular/) and [Rowen](https://www.framer.com/community/marketplace/templates/rowen/).
